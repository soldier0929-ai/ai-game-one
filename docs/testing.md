## 性能和验证边界

云端 Chromium 使用 CPU SwiftShader 软件渲染，不能代表真实显卡或手机性能。排除其他浏览器进程后，1440×900、第一关静止瞄准的独立 60 秒样本平均 4.15 FPS，帧时间中位数 200ms、P95 483.4ms；该软件渲染环境未达到流畅性能目标。原始采样见 `performance-isolated.json` 与 `frame-times-isolated.json`。完整验收中的早期性能采样与另一审查浏览器有短暂重叠，应以独立样本为准。

真实桌面 GPU、实体 Android/iPhone、Safari/iOS 尚未验证；触屏模拟不能替代真机。可选 WebMCP 适配器有单元测试，当前浏览器没有验证原生 WebMCP 集成。用户应使用支持 WebGL 和 WebAssembly 的现代浏览器。

独立代码审查没有发现剩余阻塞缺陷，报告见 `docs/review.md`。私有站点发布后的线上冒烟验证另附于交付归档，避免将本地验证描述为线上验证。
